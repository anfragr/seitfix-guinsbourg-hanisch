Ästhetische Prothetik

Zahnersatz auf Implantaten

Von der Einzelkrone bis zum Zahnersatz für den ganzen Kiefer, auf Implantaten festsitzend oder stabilisiert.

Das Prinzip

Sind die Implantate im Knochen eingeheilt, dienen sie als Träger für den Zahnersatz. Er wird schon bei der Planung entworfen, damit die Position der Implantate zum künftigen Zahn passt.

Wie die Implantate gesetzt werden, erfahren Sie im Bereich Implantologie. Hier geht es um den Zahnersatz, den sie tragen können.

Die Lösungen

  • Krone auf einem ImplantatEin fehlender Zahn, ein Implantat, eine Krone. Die Nachbarzähne bleiben unversehrt.
  • Brücke auf ImplantatenMehrere fehlende Zähne nebeneinander, ersetzt durch eine Brücke auf zwei oder mehr Implantaten.
  • Festsitzender Zahnersatz für den ganzen KieferErsetzt alle Zähne eines Kiefers, je nach Fall auf vier bis sechs Implantaten. Er lässt sich nicht herausnehmen.
  • Herausnehmbare Prothese auf ImplantatenEine Vollprothese, die auf zwei bis vier Implantaten einrastet. Sie hält gut und wird zur Reinigung herausgenommen.

Verschraubt oder zementiert

Der Zahnersatz kann auf die Implantate geschraubt oder auf Aufbauteile (Abutments) zementiert werden. Verschraubten Zahnersatz kann der Zahnarzt für eine Kontrolle oder Reparatur abnehmen. Welche Variante gewählt wird, hängt von der Situation und der Position der Implantate ab.

Pflege

Zahnersatz auf Implantaten wird täglich gereinigt, besonders sorgfältig am Übergang zum Zahnfleisch. Interdentalbürstchen, spezielle Zahnseide oder eine Munddusche helfen, diese Stellen zu erreichen.

Bei regelmäßigen Kontrollen in der Praxis lässt sich eine Entzündung rund um die Implantate früh erkennen.

Häufige Fragen

Kann festsitzender Zahnersatz für den ganzen Kiefer an einem Tag eingesetzt werden?

In manchen Fällen kann noch am Tag der Implantation ein festsitzender provisorischer Zahnersatz eingesetzt werden. Das hängt von der Knochenqualität und der erreichten Stabilität ab. Der endgültige Zahnersatz wird nach der Einheilung angefertigt.

Kann ich meine alte Vollprothese behalten?

Manchmal lässt sich eine vorhandene Vollprothese so anpassen, dass sie auf Implantaten einrastet. Der Zahnarzt prüft bei der Untersuchung, ob sie sich dafür eignet.
